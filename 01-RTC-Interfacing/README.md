# Experiment 01: RTC Interfacing Using ARM7 LPC2138

## Subject
Microcontrollers and Applications (TE-ENTC, SPPU)

## Aim
To interface the Real-Time Clock (RTC) of the ARM7 LPC2138 microcontroller and display date and time using UART.

## Hardware and Software Requirements
- ARM7 LPC2138 Microcontroller
- 12 MHz Crystal
- 32.768 kHz RTC Crystal
- Proteus 8 Professional
- Keil µVision 4
- Virtual Terminal

## Controller
ARM7 LPC2138

## Communication
UART0

## Description
The internal RTC of LPC2138 maintains date and time. UART0 is used to transmit the RTC values to the Virtual Terminal.

## Expected Output
The Virtual Terminal displays the current date and time.
